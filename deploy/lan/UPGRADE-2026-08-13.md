# 2026-08-13 部署与升级说明

## 适用范围

本说明对应仓库中的 2026-08-13 可迁移基线，包含：

- 项目“第一分级 → 第二分级 → 项目”严格层级及自动直属分级。
- 项目分类迁移时的资料、Wiki、会议记录库存核对与进度任务。
- 统一“上传资料”、统一“AI 工作台”和统一“智慧 Wiki”工作区。
- 全员 AI Token 排行榜与 CC Switch 官方统计去重。
- 共享电脑上的 CC Switch 临时归属会话，可按成员开始、定时/手动结束并回传最终用量。
- 成员管理、普通成员项目范围权限和 ClickHouse 并发查询修复。
- Company Memory 在安全校验通过后的项目 Wiki 直接发布。

## 全新部署

1. 复制 `.env.lan.example`，或运行 `New-LanEnv.ps1` 生成 `.env`。
2. 从目标 Supabase 实例填写真实 `SUPABASE_JWT_SECRET` 和 `SUPABASE_SERVICE_ROLE_KEY`。
3. 按文件名顺序执行 `supabase/migrations/` 的全部迁移。
4. 运行 `Build-Images.ps1` 构建当前便携镜像。
5. 运行 `Start-Lan.ps1` 启动服务。
6. 仅在演示环境运行 `Initialize-Database.ps1`；正式环境自行创建组织、成员和项目。

## 已有环境升级

升级前必须分别备份 PostgreSQL、ClickHouse，以及当前 `.env` 和 Compose 配置。不要把备份提交到 Git。

从早于 2026-08-10 的版本升级时，至少需要按顺序应用：

1. `20260810000000_fix_cc_switch_token_semantics.sql`
2. `20260810010000_add_system_admin_departments_and_username.sql`
3. `20260810020000_add_project_creation_requests.sql`
4. `20260810030000_fix_dynamic_department_schema.sql`
5. `20260810040000_add_project_management_hierarchy.sql`
6. `20260811010000_simplify_meeting_records.sql`
7. `20260811020000_add_team_member_management.sql`
8. `20260812000000_enforce_strict_project_hierarchy.sql`
9. `20260812010000_add_project_department_migrations.sql`
10. `20260813000000_add_shared_cc_switch_sessions.sql`

迁移会把仍挂在第一分级的项目移动到对应“直属分级”，并同步资料、项目记忆草稿和已创建申请的分类快照。不要跳过中间迁移，也不要手工把项目重新挂回第一分级。

迁移完成后重新构建并仅重建有变化的服务：`api`、`project-wiki-worker`、`ai-worklog-worker`、`member-wiki-worker`、`smartbrain`。如果目标机器已运行 GPU RAG，重建模型服务时必须带上 `compose.rag-gpu.override.yaml`，否则可能回落到 CPU。

## 验收

- `GET /health` 返回 200。
- `/admin`、`/uploads`、`/wiki`、`/leaderboard` 可访问。
- 项目只能位于第二分级，每个第一分级恰好一个“直属分级”。
- 管理员保存 PROJECT PROFILE 后，管理按钮和待审批区仍保留。
- 项目分类迁移完成后任务为 `completed`、进度 100、`verified=true`。
- 快速切换 AI 工作台页签时，ClickHouse 不出现同 session 并发查询错误。
- 共享设备归属会话能开始、停止、最终同步，且不会把同一请求归属给多个成员。
- 390px 窄屏无页面级横向溢出，浏览器控制台无 warn/error。

## 回滚边界

- 代码回滚不能替代数据库回滚；若已经应用迁移，应从升级前 PostgreSQL 备份恢复。
- 不要删除生产机器上的 Docker 网络恢复备份或历史数据库 dump，除非已另行确认可恢复性。
- 本仓库不包含生产数据库、Docker volume、机器专用镜像 ID或真实凭据。

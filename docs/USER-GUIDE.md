# 智慧大脑 Agent — 用户使用手册

> 5 分钟上手。

## 1. 打开系统

浏览器输入：

```
http://192.168.1.40:3001
```

如果打不开，问服务器侧管理员。

## 2. 登录

- 邮箱：你公司邮箱
- 密码：第一次用管理员给你的临时密码（首次登录会要求改）

## 3. 选项目

登录后顶部有项目下拉框，**你只能看到自己有权限的项目**。

| 你的角色 | 能干什么 |
|---|---|
| Owner | 管理项目 + 上传/删除 + 查询 |
| Admin | 管理项目成员 + 上传/删除 + 查询 |
| Developer | 上传/删除 + 查询 |
| Viewer | 只查询 |

如果看不到任何项目——联系管理员把你加进去。

## 4. 上传文档

进入 `/documents` 页：

1. 选项目（顶部下拉框）
2. 点"选择文件"
3. 选 PDF / Markdown / TXT 文件
4. 点"Upload"
5. 等几秒，状态变 "ready"

**支持的文件类型**：
- PDF（`.pdf`）
- Markdown（`.md`）
- 纯文本（`.txt`）

**不支持**：Word (.docx)、Excel、图片（OCR 暂未做）。

## 5. 提问

进入 `/chat` 页：

1. 选项目
2. 输入框输入问题，例如：
   - "我们公司的产品定价是什么？"
   - "如何部署？"
   - "项目里有什么 FAQ？"
3. 按 `Ctrl + Enter` 或点 "Ask"
4. 看 AI 答案 + 来源

### 答案格式

```
[AI 答案]

[来源] 1. pricing.md (page 5) · score 0.93
       2. faq.txt (line 12) · score 0.88
       ...
```

点 "N source chunk(s)" 折叠看原文片段。

### 搜索 vs Ask

- **Ask** = 用 LLM 生成答案（要等几秒，答案流畅）
- **Search** = 只列匹配的文档片段（快，不生成答案）

不确定用哪个？先用 Ask。

## 6. 看历史

**当前版本不存对话历史**——刷新页面就清空。后续版本会加。

## 7. 管理项目（仅 admin+）

进 `/projects-admin`：

- 看你有权限的所有项目
- 目前只读，**创建项目 / 加成员要管理员用 API**

## 8. 查审计日志（仅 admin+）

进 `/admin-audit`：

- 看所有用户最近的搜索 / 上传 / 登录
- 可按 action 类型过滤（search/answer/upload/login）
- 可按用户 ID 过滤

## 9. 退出

右上角头像 → Sign out。

## 10. 常见问题

**Q: 答案不准确？**
A: 检索依赖 chunk 大小。当前 512 token 切块。复杂文档建议拆成多个小文档上传。

**Q: 中文 query 搜不到？**
A: 系统支持中英文。但同一句话用英文问可能更好——embedding 模型对中英混合有偏。

**Q: 上传后多久能搜到？**
A: 1-3 秒（嵌入 + 写库）。刷新 `/documents` 看 status="ready" 即可。

**Q: 我能上传别人项目的文档吗？**
A: 不能。你只能往自己有 developer+ 角色的项目上传。联系 admin 加你。

## 11. 数据隐私

- 所有数据在服务器本地，不上云
- LLM 调用走 MiniMax-M3（公司内网代理）
- 查询内容**不存原文**，只存查询长度和命中数
- 每次操作都有审计日志（admin 可看）

## 12. 反馈问题

发现 bug / 有改进建议：找管理员。

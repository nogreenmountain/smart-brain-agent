智慧大脑 AI 使用记录与区间报告使用手册
版本：2026-07-29-r6-exe

一、访问地址

智慧大脑：http://192.168.1.40:3002
AI 使用页面：http://192.168.1.40:3002/workday

二、普通员工使用方法

1. 使用自己的智慧大脑用户名和密码登录。
2. 点击左侧“AI 工作日”。
3. 页面自动进入“我的 AI 使用”，默认查询最近 7 天。
4. 可以修改开始日期、结束日期和 AI 来源，再点击“查询记录”。
5. 页面显示 Token 总量、自然日日均、使用记录数、活跃天数和错误数。
6. 点击一条会话可以展开员工可见的用户消息和 AI 文本回复，并查看模型、输入
   Token、输出 Token、总 Token、耗时及关联 Trace。

普通员工不需要选择项目或员工，也不能查看其他员工的记录。普通员工页面没有
“生成区间工作报告”按钮。

三、管理员使用方法

1. 使用管理员账号登录并进入“AI 工作日”。
2. 页面自动进入“团队 AI 使用”。
3. 按“部门 -> 项目 -> 员工”顺序选择范围。
4. 选择开始日期、结束日期和可选的 AI 来源，点击“查询记录”。
5. 检查统计、每日 Token 趋势、高频使用时段和具体 AI 使用记录。
6. 查询到数据后，点击“生成区间工作报告”。

报告严格绑定当前员工、项目和日期区间，包括：

- 高频使用时间段；
- 区间 Token 总量；
- 按所选自然日计算的日均 Token；
- 完成了什么；
- 实现了什么；
- 遇到了什么问题；
- 解决了什么问题。

统计数字由系统确定性计算，大模型只负责归纳记录内容。证据不足时报告会明确说明，
不会把推测写成事实。报告目前不会自动写入知识库或员工档案。

四、统计口径

- 日期按 Asia/Shanghai 时区解释，包含开始日期和结束日期。
- 自然日日均 Token = 区间 Token 总量 / 所选自然日天数。
- 活跃天数单独显示，便于区分集中使用和持续使用。
- ChatGPT 网页版 Token 由监控扩展估算；CC Switch/Codex/Claude 优先使用
  OpenTelemetry 上报值。
- Codex/Claude 本地会话正文与同时间 Trace 会自动合并，避免重复计算。
- 单次查询日期区间最长 366 天。

五、权限与审计

- 普通员工只能查看由登录账号推导出的本人 employee_id。
- 手工修改请求参数查询其他员工会返回 HTTP 403。
- 管理员只能查看其可管理组织下的项目及项目成员。
- 查看记录写入 ai_usage_view 审计；生成报告写入 ai_usage_report 审计。

六、当前数据边界

- ChatGPT 网页监控保存并展示员工可见的用户消息和 AI 文本回复。
- r6 EXE 一键安装器会同步 Codex 和 Claude Code 中员工可见的用户消息、AI 文本回复、
  模型及 Token；首次安装同步最近 7 天，此后每两分钟同步一次。
- 系统提示词、密钥、工具参数、命令输出和本地文件内容不会作为对话正文上传。
- 如果页面提示“尚未完成正文同步”，应检查员工电脑上的
  “SmartBrain AI Conversation Sync”定时任务和服务器 8000 端口连接。
- ChatGPT 个人桌面端目前仍不支持本地直接采集，应使用受监控的 ChatGPT 网页快捷方式。

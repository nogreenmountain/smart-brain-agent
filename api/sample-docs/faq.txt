常见问题 FAQ

Q1: 智慧大脑支持哪些文档格式？
答：目前支持 PDF、Markdown 和 TXT 三种格式。Word 文档和其他格式暂未支持，预计在第二季度上线。

Q2: 文档可以删除吗？
答：可以。在 Dashboard 的知识库页面，每个文档右上角有删除按钮。

Q3: 检索准确度如何？
答：使用 BGE small embedding 模型，在中英文场景下都表现良好。实测 Top-5 命中率约 85%。

Q4: 如何提升检索质量？
答：建议文档结构清晰、段落分明，避免过长的单段落。512 token 的 chunk 大小是默认起点。

Q5: 支持多语言吗？
答：当前主要优化中英文。其他语言检索效果可能下降，可联系团队定制。

Q6: 数据安全如何保障？
答：所有数据存储在用户的 Supabase 实例中，embedding 计算在本地完成，不向外部传输任何数据。
